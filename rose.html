ROSE3軸ロゼットゲージ解析（直角型・鋼）

Rosette-Oriented Stress Evaluation

設定

0°-45°-90°ロゼットゲージのひずみ（μ）から，平面応力状態の応力を求めます。降伏後は，ひずみの変化分ごとに，von Mises相当応力が降伏強度（硬化を含む）を超えないよう応力を計算します。

材料定数

N/mm²
N/mm²
推奨値：0（完全弾塑性）
主応力平面の von Mises 楕円（σ1² − σ1σ2 + σ2² = fy²）を1°刻み361点で出します。列は θ (deg)，σ1，σ2，σ1/fy，σ2/fy です

εx = εa，εy = εc，γxy = 2εb − εa − εc。主応力方向 θ は a（x軸）から b 側へ測った角度（°）です。初期状態は応力 0 とします。

von Misesの降伏条件：多軸の応力状態でも，次の相当応力 σeq が降伏強度 fy に達したときに降伏するとみなす条件です。平面応力では σeq = √(σx² − σxσy + σy² + 3τxy²)（主応力で表すと √(σ1² − σ1σ2 + σ2²)）となります。単軸引張では σeq = σx となり，1軸の降伏強度と一致します。

ヘッダーなし。3列で1組（a, b, c の順）とし，複数組（3n列）に対応。区切りはカンマ・タブ・空白のいずれも可。値の単位は μ（×10⁻⁶）。1組の中に空欄がある行は，その組を空欄で出力します。

出力CSVは，1行目が項目名，2行目以降が各ステップの値です。各組につき σx，σy，τxy，最大主応力 σ1，最小主応力 σ2，主応力方向 θ，von Mises相当応力 σeq の7列を出力します（項目名の例：R1_sx）。θ は a（x軸）から b 側へ測った σ1 の方向（°）で，応力の単位は N/mm² です。
