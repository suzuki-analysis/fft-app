GAUGEひずみ→応力変換（鋼）

Gauge Analysis of Uniaxial and Generalized Elastoplasticity

設定

ひずみゲージの値（μ）を応力（N/mm²）に変換します。1軸ゲージは，バイリニアまたは修正Menegotto-Pintoモデルで除荷・繰返しの履歴を追います。3軸ロゼットは，平面応力のvon Mises弾塑性で解きます。

主応力平面の von Mises 楕円（σ1² − σ1σ2 + σ2² = fy²）を1°刻み361点で出します。列は θ (deg)，σ1，σ2，σ1/fy，σ2/fy です

移動硬化：降伏後，弾性範囲の幅（2fy）を保ったまま降伏点が移動します。引張側で応力が上がった分，圧縮側では早く降伏します。

等方硬化：降伏後，引張・圧縮の降伏応力がともに同じだけ大きくなり，繰り返すほど弾性範囲が広がります。

修正Menegotto-Pinto：一度降伏した後の除荷・再載荷で，応力が曲線的に変化します。繰返しを受けた鋼材で降伏点が不明瞭になる現象（バウシンガー効果）を，実際に近い形で表します。

いずれも除荷は E の勾配で戻り，初期状態は応力 0 です。図は違いが分かるよう β = 0.08 として傾きを誇張しています（点線は ±fy）。β = 0 では移動硬化と等方硬化は同じ結果になります。

εx = εa，εy = εc，γxy = 2εb − εa − εc。主応力方向 θ は a（x軸）から b 側へ測った角度（°）です。初期状態は応力 0 とします。

von Misesの降伏条件：多軸の応力状態でも，次の相当応力 σeq が降伏強度 fy に達したときに降伏するとみなす条件です。平面応力では σeq = √(σx² − σxσy + σy² + 3τxy²)（主応力で表すと √(σ1² − σ1σ2 + σ2²)）となります。単軸引張では σeq = σx となり，1軸の降伏強度と一致します。
